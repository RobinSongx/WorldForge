# 2026-10-01—10-07 开发计划（每天 5 小时）

制定于 2026-09-29。总预算 **35 小时**。执行依据为 [路线图](../ROADMAP.md)：Windows 先发布；10/04 前收口 0.0.3 的 Mesh/Scene 闭环，10/05 起进入 v0.1 Hybrid 的首个垂直切片。日期是工作安排，不等于版本验收通过或 Release 日期。

本周不扩展 Web、ROS2、插件、完整 CLI/Agent 或内置重建训练器。外部采集/重建工具只做可行性验证；在基础 Mesh 与 GS 显示可靠之前，不把“混合世界”写成已完成。

每天最后一小时包含可复现检查与记录，不以“能编译”代替功能验收。凡改 C++，执行 Google 风格检查、Windows 构建和相关测试；渲染改动还需固定资产 GPU 截图/指标。10/04 和 10/07 分别评估版本门槛，按证据推迟未达标项，不挪用后续任务的时间掩盖缺口。

若 10/01–10/02 的 PBR 超时，先保留因子和材质正确性，贴图扩展后移；若项目包超时，保留现有 Scene 保存/重开并标明不可搬移。无论哪种情况，都不要用减少验证或跳过失败回滚来赶 10/05 的 GS 工作。10/05–10/07 只要求可复现首切片，完整 Hybrid、项目搬移闭环和 CUDA 优化仍按 v0.1/v0.3 路线图推进。
