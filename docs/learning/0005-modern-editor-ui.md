# 现代编辑器 UI：工作台第一轮改造

2026-09-29。目标参考用户提供的“现代编辑器参考”会话：WorldForge 是 Mesh/3DGS 编辑器与未来重建工作流入口，当前这轮只调整**已实现** Mesh 工作台，不把未来 GS、重建、导出能力画成可点击空壳。

## 已实现

- 默认以 Viewport 为主区域；Scene 和 Inspector 常驻。Console、Assets、Performance 默认收起，通过 View 菜单按需打开时为它们分配底部区域。更改底部面板可见性时重建默认停靠布局；普通拖动仍由 ImGui 保存。
- 使用新停靠 ID 迁移旧默认布局，避免本机旧 `layout.ini` 继续占据大量视口空间。`View → Reset layout` 使用当前面板开关重新排布，不擅自打开已关闭的面板。
- 主题集中在 `editor_theme`：深色中性底色、暖色状态/选中点缀、统一间距与圆角；从基准样式按显示 DPI 重建，防止重复缩放。
- 文件名进入顶栏；Scene 保留新增、清选和层级，增加显式 GLB 导入入口；Viewport 保留网格、线框、选择覆盖、Frame 和相机重置，导入状态在画面内显示。
- 沿用既有 FBO、帧缓冲比例、相机与选中逻辑。EditorState、渲染器和 Scene 文件格式均未因这次 UI 调整而改变。

## 下一轮体验检查

当前的自动 UI 测试覆盖窗口存在、选中/取消、显示开关及 Scene 文档流程；GPU smoke 可生成固定截图。仍需人工在多显示器 DPI、窄窗口和原生文件选框下体验停靠与输入。GS/Reconstruct 工作区只在对应功能真的落地时加入。
